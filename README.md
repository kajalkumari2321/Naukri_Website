# Job Hai - नौकरी पोर्टल 🚀

एक सुंदर और modern job portal website Django में बनाया गया है।

## Features ✨

- सुंदर gradient background design
- Professional images के साथ job cards
- Responsive layout
- Hindi language support
- Modern UI/UX
- Admin panel से jobs manage करें

## Setup Instructions

1. Server चालू करें:
```bash
python manage.py runserver
```

2. Browser में खोलें:
```
http://127.0.0.1:8000/
```

3. Admin panel access करने के लिए:
```bash
python manage.py createsuperuser
```
फिर जाएं: http://127.0.0.1:8000/admin/

## Project Structure

- `jobs/` - Main app with models, views
- `templates/` - HTML templates
- `static/css/` - Styling files
- `jobhai/` - Project settings

## Technologies Used

- Django 5.0
- HTML5
- CSS3
- Unsplash Images (high-quality professional images)
